# Step 3 - Financial Rules

This folder groups Add and Edit wizard cases for Financial Rules and the migrated Financial Rules suite.

- Add/Edit wizard specs: `add/` and `edit/`.
- Financial Rules suite specs, helper, source cases and coverage notes: `add/`.
- Workflow detail: [Add](../../../../docs/workflow-documentation/03-Financial-Rules/add/README.md) and [Edit](../../../../docs/workflow-documentation/03-Financial-Rules/edit/README.md).

Run the Financial Rules suite on Chromium with `npm run test:financial-rules`. The LPC project is filtered separately by the `FLOW-LPC-*` ID pattern.
