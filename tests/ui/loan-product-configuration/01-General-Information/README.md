# Step 1 - General Information

This folder groups Add and Edit wizard cases for the first LPC step, together with the General Product Setup suite.

- Add/Edit wizard specs: `add/` and `edit/`.
- General Product Setup specs, helper, source cases and coverage notes: `add/`.
- Source case records include retired cases for traceability; retired cases do not have executable specs.
- Workflow detail: [Add](../../../../docs/workflow-documentation/01-General-Information/add/README.md) and [Edit](../../../../docs/workflow-documentation/01-General-Information/edit/README.md).

Run the General Product Setup suite on Chromium with `npm run test:general-product-setup`. The LPC project is filtered separately by the `FLOW-LPC-*` ID pattern.
