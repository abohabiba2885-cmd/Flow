# Step 2 - Loan Structure

This folder groups Add and Edit wizard cases for Loan Structure and the migrated Loan Structure suite.

- Add/Edit wizard specs: `add/` and `edit/`.
- Loan Structure suite specs, helper, source cases and coverage notes: `add/`.
- Workflow detail: [Add](../../../../docs/workflow-documentation/02-Loan-Structure/add/README.md) and [Edit](../../../../docs/workflow-documentation/02-Loan-Structure/edit/README.md).

Run the Loan Structure suite on Chromium with `npm run test:loan-structure`. The LPC project is filtered separately by the `FLOW-LPC-*` ID pattern.
